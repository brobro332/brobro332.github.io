# DATT v2 리빌드 로드맵

# 프로젝트 방향 재정의

DATT v2는 기존의 단순 장소 탐색 서비스가 아니다.

핵심 방향은:

```text
공간에 기억을 남기는 위치 기반 기록 플랫폼
```

이다.

---

# 핵심 기능

## 1. 장소 기반 Anchor 기록

사용자는:

- 장소 검색
    
- 지도 탐색
    
- Anchor 기록
    
- 이미지 업로드
    
- 리뷰 작성
    

을 수행할 수 있다.

---

## 2. 내부 데이터 기반 장소 성장 구조

외부 리뷰/평점 의존 없이:

- Anchor 수
    
- 리뷰 수
    
- 이미지 수
    
- 저장 수
    
- 공유 수
    

를 기반으로 장소가 성장한다.

---

## 3. 장소 그룹화

동일 장소를 하나의 대표 장소 그룹(place_group)으로 묶는다.

예:

```text
스타벅스 성수점
스타벅스 성수역점
스타벅스 성수 DT점
```

→ 하나의 대표 장소 그룹으로 관리.

---

## 4. 컬렉션 기반 공유

사용자는:

```text
성수 작업 카페 모음
서울 심야 산책 장소
```

등 자신만의 장소 그룹을 만들고 공유할 수 있다.

---

## 5. 기록 기반 게임화

경쟁 중심이 아니라:

```text
기록 축적 중심
```

의 게임화 구조를 적용한다.

예:

- 성수 기록가
    
- 심야 탐험가
    
- Anchor Keeper

# 핵심 방향

앞으로 중요한 것은:

```text
기능 구현
```

보다

```text
왜 그렇게 설계했는가
```

를 설명 가능한 수준까지 가는 것이다.

DATT v2의 핵심은:

```text
공간에 기억을 남기는 기록 플랫폼
```

이라는 방향성을 유지하는 것이다.
