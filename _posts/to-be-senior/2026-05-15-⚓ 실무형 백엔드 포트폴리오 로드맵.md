# DATT 프로젝트란?

DATT는 단순 맛집 검색 서비스가 아니다.

핵심 목표는:

```text
"특정 장소를 기준으로 주변 경험을 탐색하고,
그 경험을 사용자들과 공유하는 플랫폼"
```

을 만드는 것이다.

즉:

```text
장소 검색
→ 주변 탐색
→ Anchor 생성
→ 공유
→ 리뷰
→ 사용자 활동
→ 성장
```

흐름을 가진다.

예를 들어 사용자가:

```text
"성수에서 데이트할 곳 찾기"
```

상황에서 특정 장소에 Anchor를 생성하면:

```text
맛집
카페
술집
숙소
놀거리
```

등을 자동 큐레이션한다.

즉 DATT의 핵심은:

```text
위치 기반 경험 탐색 + 사용자 반응 데이터 축적
```

이다.

최종 목표는 다음 흐름을 완성하는 것이다.

```text

→ 배포
```

```text
"위치 기반 경험 탐색 플랫폼 MVP 구축"
```

이 목표다.

# 마무리

DATT는 단순 장소 검색 서비스가 아니다.

핵심은:

```text
"특정 지역을 기준으로
좋은 경험을 탐색하고 공유하는 것"
```

이다.

즉:

```text
검색
→ 탐색
→ 큐레이션
→ 리뷰
→ 공유
→ 성장
```

흐름을 가진다.

이번 프로젝트를 통해:

```text
Spring Boot
JWT 인증
QueryDSL
Spring Batch
위치 기반 검색
추천 구조
Gamification
프론트/백엔드 통합
배포 경험
```

까지 전체 서비스 개발 흐름을 경험하는 것이 목표다.
