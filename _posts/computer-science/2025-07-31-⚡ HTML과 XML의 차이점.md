### `HTML`
- `HyperText Markup Language`의 약자로,  웹 페이지를 만들기 위한 표준 마크업 언어
- `HyperText`: 다른 문서나 웹 페이지로 연결되는 링크 따위의 텍스트
- `Markup Language`: 문서의 구조를 태그를 이용해 표시하는 언어
- 목적: 웹 브라우저에 텍스트, 이미지 등을 표시하기 위함
- 정해진 태그만 사용 가능 (`<div>`, `<h1>`, `<p>` 등)
- 의미보다는 화면 표시에 초점

### `XML`
- `eXtensible Markup Language`의 약자로,  확장 가능한 마크업 언어
- `eXtensible`: 고정된 문서 구조를 따르지 않고, 개발자나 시스템이 자신만의 태그와 구조를 정의할 수 있도록 확장 가능
- 목적: 데이터를 저장하고 전달하기 위함
- 사람도 읽을 수 있고, 기계도 읽을 수 있음
- `HTML`처럼 태그 기반이지만, 의미 중심
- 브라우저가 직접 렌더링하지 않음

### `HTML` vs `XML` 차이점 정리
|구분|`HTML`|`XML`|
|---|---|---|
|**의미**|`HyperText Markup Language`|`eXtensible Markup Language`|
|**목적**|웹 콘텐츠 표현|데이터 저장 및 전송|
|**태그**|정해진 태그만 사용 가능|사용자가 태그 직접 정의 가능|
|**유연성**|구조가 고정됨|구조가 확장 가능함|
|**표현 방식**|화면에 어떻게 보일지를 정의|데이터가 무엇을 의미하는지 정의|
|**사용 예시**|웹 페이지|`RSS`, `SOAP`, 설정 파일 등|

### 회고
- 몇 년 동안 `HTML`을 써오면서도 “`HTML`이 정확히 뭔가요?”라는 질문에 답하기 어려웠다.
- `XML`의 경우 단순히 설정 파일이나 `MyBatis` 쿼리를 매핑하는 정도의 역할이라고 생각했는데 데이터 저장 및 전송 개념이었다는 점이 새로웠다.
- 빠르게 적용하는 것도 중요하지만, 신뢰성 있는 개발자가 되려면 기술을 제대로 이해하고 사용하는 것이 더 중요하다는 생각이 들었다.
