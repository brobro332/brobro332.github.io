### `Java`의 특징
#### `OOP` 언어
- 모든 것이 객체로 구성
- 코드 재사용, 유지보수 용이

####  플랫폼 독립적
- 자바 바이트코드(`.class` 파일)를 `JVM`에서 실행
- `OS`에 상관없이 실행 가능
        
#### 자동 메모리 관리 (`Garbage Collection`)
- 개발자가 직접 메모리 해제 안 해도 됨
- `JVM`이 사용하지 않는 객체 자동 정리
        
#### 멀티스레드 지원
- 동시에 여러 작업 처리 가능
- 병렬 처리와 고성능 앱 작성에 유리
        
#### 풍부한 표준 라이브러리 제공
- 네트워킹, 입출력, 컬렉션, `GUI` 등 다양한 `API` 포함
        
#### 강한 타입 검사
- 컴파일 시점에 타입 오류 체크
- 안정적인 코드 작성 가능
        
#### 보안성
- `JVM` 내에서 실행돼 직접 하드웨어 접근 차단
- 샌드박스 모델로 안전한 실행 환경 제공
        
#### 동적 바인딩
- 실행 시점에 메서드 호출 결정
- 유연한 다형성 구현

### `XML`
- `eXtensible Markup Language`의 약자로,  확장 가능한 마크업 언어
- `eXtensible`: 고정된 문서 구조를 따르지 않고, 개발자나 시스템이 자신만의 태그와 구조를 정의할 수 있도록 확장 가능
- 목적: 데이터를 저장하고 전달하기 위함
- 사람도 읽을 수 있고, 기계도 읽을 수 있음
- `HTML`처럼 태그 기반이지만, 의미 중심
- 브라우저가 직접 렌더링하지 않음

### `HTML` vs `XML` 차이점 정리
|구분|`HTML`|`XML`|
|---|---|---|
|**의미**|`HyperText Markup Language`|`eXtensible Markup Language`|
|**목적**|웹 콘텐츠 표현|데이터 저장 및 전송|
|**태그**|정해진 태그만 사용 가능|사용자가 태그 직접 정의 가능|
|**유연성**|구조가 고정됨|구조가 확장 가능함|
|**표현 방식**|화면에 어떻게 보일지를 정의|데이터가 무엇을 의미하는지 정의|
|**사용 예시**|웹 페이지|`RSS`, `SOAP`, 설정 파일 등|
