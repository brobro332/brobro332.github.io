### 🔹 개요
- 웹 문서의 구조를 프로그래밍적으로 표현한 객체 모델
- `HTML`, `XML` 문서의 각 요소를 객체로 표현하여 접근과 조작이 가능하도록 함
- 브라우저가 문서를 파싱해 생성하며, 자바스크립트 등에서 `DOM`을 통해 웹 페이지를 동적으로 변경할 수 있음

### 🔹 주요 특징
- 문서의 각 요소(`tag`, `attribute`, `text` 등)가 노드(`node`)로 표현됨
- 트리 구조로 구성되어 있어 부모-자식 관계로 연결됨
- 표준화된 인터페이스로 다양한 언어에서 접근 가능

### 🔹 `DOM` 트리 구조 예시
- 최상위 노드: `Document` 객체
- `Document` 아래에 `html` 요소, 그 아래에 `head`와 `body` 요소 등 계층 구조로 연결됨

### 🔹 활용 예시
- 자바스크립트로 특정 요소 선택 및 내용 변경
- 이벤트 처리 (클릭, 입력 등 사용자 동작에 반응)
- 새로운 요소 생성 및 삭제로 페이지 동적 변경

### 🔹 요약
- `DOM`은 웹 문서의 구조를 객체로 표현한 것
- 개발자가 스크립트를 통해 웹 페이지 내용을 동적으로 조작할 수 있게 하는 핵심 기술
